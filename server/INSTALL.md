# Сервер на хостинге-контейнере

1. Загрузи `main.py` в корень сервера (там, где `/home/container`).
2. Нажми **Start**. В консоли появится ключ `ss://…` — скопируй его целиком.
3. Вставь ключ в приложении.

Порт берётся из панели (`SERVER_PORT`, по умолчанию 13666), нужен TCP и UDP.
Если IP в ключе неверный — добавь переменную окружения `PUBLIC_IP`.
Ключ также лежит в файле `key.txt`.
