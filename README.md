## Почему Шаурма VPN

| | |
|---|---|
| ⚡ **Быстро** | Лёгкий протокол Shadowsocks — минимум задержек и расхода батареи |
| 🔒 **Безопасно** | Весь трафик шифруется, личные данные остаются при тебе |
| 🌯 **Просто** | Одна кнопка. Шаурма крутится — значит, защита работает |
| 🚫 **Без рекламы** | Никаких баннеров, регистраций и подписок |

## Как начать

1. **Скачай** приложение кнопкой выше и открой файл `ShaurmaVPN.apk`
   *(если Android спросит — разреши установку из этого источника)*
2. **Войди** через Google и придумай свой юзер в сети Шаурма VPN
3. **Получи подписку** в Telegram-боте: бесплатные 12 часов или тариф на 1, 3, 6, 12 месяцев — укажи там свой юзер
4. **Нажми на шаурму** — когда она закрутится, ты подключён. Ключи вводить не нужно
