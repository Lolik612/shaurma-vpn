## Почему Шаурма VPN

| | |
|---|---|
| ⚡ **Быстро** | Современный протокол WireGuard — минимум задержек и расхода батареи |
| 🔒 **Безопасно** | Весь трафик шифруется, личные данные остаются при тебе |
| 🌯 **Просто** | Одна кнопка. Шаурма крутится — значит, защита работает |
| 🚫 **Без рекламы** | Никаких баннеров, регистраций и подписок |

## Как начать

1. **Скачай** приложение кнопкой выше и открой файл `ShaurmaVPN.apk`
   *(если Android спросит — разреши установку из этого источника)*
2. **Вставь ключ доступа**, который тебе выдали, и нажми «Продолжить»
3. **Нажми на шаурму** — когда она закрутится, ты подключён

## Вопросы

<details>
<summary><b>Где взять ключ?</b></summary>

Ключ — это строка вида `shaurma://…`. Его выдаёт владелец сервиса.

</details>

<details>
<summary><b>Как обновить приложение?</b></summary>

Скачай новую версию по той же кнопке и установи поверх старой — ключ сохранится.

</details>

<details>
<summary><b>Как сменить ключ?</b></summary>

На главном экране нажми на карточку «Выбранная локация» и вставь новый ключ.

</details>
