# Шаурма VPN

Android-приложение: кнопка-шаурма, при включении VPN крутится. Протокол — WireGuard.

## 1. Сервер
Скопируй `server/setup-server.sh` на VPS (Ubuntu/Debian) и запусти от root:

    bash setup-server.sh

Скрипт установит WireGuard и выведет клиентский конфиг (он же лежит в `/root/client.conf`).
Не забудь открыть порт 51820/udp в файрволе хостинга.

## 2. Приложение
1. Залей этот проект в репозиторий на GitHub (ветка `main`).
2. Вкладка **Actions → Build APK** — сборка запустится сама (или кнопкой Run workflow).
3. Скачай артефакт **ShaurmaVPN-apk** → внутри `app-debug.apk`, поставь на телефон.
4. Открой приложение → нажми «Выбранная локация» → вставь содержимое `client.conf` → Сохранить.
5. Нажми на шаурму.
